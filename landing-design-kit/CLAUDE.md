# Landing builder rules
- For any design/landing request use skills `landing-design-director` + `frontend-design`.
- Stack: React/Next.js + Tailwind + shadcn/ui + Magic UI; motion, GSAP ScrollTrigger, Lenis.
- Always propose 3 distinct directions first, then build the chosen one.
- After every section: Playwright screenshots at 1440 and 390 px, fix issues, repeat.
